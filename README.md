# Ecopark project

## Configuration

Si vous clonez ce projet, vous aurez besoin de :
- Créer un fichier `.env`, dans le dossier `backend`, reprenant la configuration démontrée dans `backend/.env.example`.
- Initialiser une base de donnée `MySQL`, avec le contenu du fichier `backend/schema.sql`.

## Premier lancement

Dès que les configurations sont effectuées, pensez à :
- Lancer MySQL pour que votre base de données soit accessible.
- Lancer l'utilitaire `launchServers.bat`, qui est à la racine du dossier de projet, pour lancer les serveurs de développement.
